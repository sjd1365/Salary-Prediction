📈 Salary Analysis & Prediction based on Experience
📋 Project Overview
This project explores the relationship between Years of Experience and Salary. Using a dataset of professional records, I performed Exploratory Data Analysis (EDA) and built a predictive foundation to understand how compensation scales with tenure.

🛠 Tech Stack
Language: Python 3.x

Libraries: - Pandas (Data manipulation)

Seaborn & Matplotlib (Statistical visualization)

NumPy (Numerical operations)

📂 Dataset Description
The dataset Salary.csv contains:

YearsExperience: Independent variable (The predictor).

Salary: Dependent variable (The target).

Size: 35 professional records.

🔍 Analysis & Insights
Correlation: A strong positive correlation of 0.98 was found, indicating that experience is a primary driver of salary.

Outliers: The data is clean with very few outliers, making it ideal for linear modeling.

Trend: The visualization shows a consistent linear growth, suggesting a predictable career progression path.
